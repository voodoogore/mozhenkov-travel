MOZHENKOV TRAVEL — ПАКЕТ ДЛЯ TILDA

ВЕРСИЯ: дизайн на основе ПЕРВОГО утвержденного макета Mozhenkov Travel — белая шапка, красный акцент, светлый hero с фотографией справа, карточки услуг, светлые блоки, красный CTA и темный футер.

1. СТРАНИЦЫ TILDA
Создайте 9 страниц и задайте URL:
  Главная: /
  Испания: /visa-spain
  Италия: /visa-italy
  Франция: /visa-france
  Долгосрочный Шенген: /long-schengen-armenia
  США: /visa-usa
  Великобритания: /visa-uk
  Другие визы: /other-visas
  Срочный загранпаспорт: /urgent-passport

На каждой странице добавьте блок T123 «HTML-код» и вставьте содержимое соответствующего файла из папки /tilda.

2. ИЗОБРАЖЕНИЯ
Все файлы лежат в /assets и отдельно в архиве images.zip. Загрузите изображения в Tilda/CDN.
В T123-коде используется префикс __ASSET_BASE__/. Если вы разместите все картинки на своем сервере в одной папке, замените __ASSET_BASE__ на URL папки, например:
  https://mozhenkov-travel.com/static/mt
Тогда __ASSET_BASE__/spain.webp превратится в https://mozhenkov-travel.com/static/mt/spain.webp.
Если Tilda выдает отдельный CDN URL на каждую картинку, замените каждый путь вручную по таблице ASSET_MAP.txt.

4. ФОРМА
Все CTA и контактные кнопки открывают popup: Имя + телефон/Telegram/WhatsApp. Карточки услуг НЕ открывают popup — они ведут на подробные страницы, как вы запросили.
Политика персональных данных: http://mozhenkov-travel.com/policy

В демо-версии форма не отправляет данные наружу. Для боевого сайта есть два варианта:
A) заменить форму на стандартную Tilda Form внутри popup;
B) вписать webhook в переменную ENDPOINT в JS и отправлять в CRM/n8n/Make.
